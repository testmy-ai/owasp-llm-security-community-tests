# Contributing to OWASP LLM Security Community Tests

Thank you for your interest in contributing to TestMy.AI's Community Edition!

## 🎯 Contribution Philosophy

This repository contains **educational reference tests** (15 foundational tests covering 3% of the attack surface) designed to teach AI security concepts. We welcome contributions that improve clarity, documentation, and usability—but we carefully curate test content to maintain quality and focus.

---

## ✅ How You Can Contribute

### 1. **Improve Documentation**
- Clarify test explanations
- Add usage examples (Python, JavaScript, cURL)
- Fix typos or grammar
- Translate documentation to other languages

### 2. **Report Issues**
- Found a test that's unclear? [Open an issue](https://github.com/testmyai/owasp-llm-security-community-tests/issues)
- Discovered a bug in usage examples? Let us know!
- Have questions about a test? Ask in discussions

### 3. **Share Knowledge**
- Write blog posts referencing these tests
- Create tutorials or videos using the tests
- Present at conferences or meetups
- Share on social media (tag @testmyai)

### 4. **Provide Feedback**
- Suggest improvements to test clarity
- Recommend better examples
- Share how you're using the tests
- Tell us what's missing from documentation

---

## ❌ What We Don't Accept

### Test Content Changes

We **do not accept pull requests** that:
- Add new test cases (we curate these carefully)
- Modify test prompts or vulnerability indicators
- Change severity ratings or OWASP mappings
- Request access to proprietary tests

**Why?** This is an educational repository with 15 curated tests. Our Professional Suite contains 505+ proprietary tests developed from real-world attacks and customer engagements. Adding more tests here would undermine the educational focus and the value of our professional service.

### Scope Expansion

We **do not accept**:
- Framework integrations (build your own on top!)
- Automation scripts (use our Professional Suite or build your own)
- Custom test runners (community can build these)
- Reporting tools (part of Professional offering)

## 📝 How to Submit a Contribution

### For Documentation Improvements:

1. **Fork the repository**
2. **Create a branch**: `git checkout -b improve-docs-llm01`
3. **Make your changes** (documentation only)
4. **Test your changes** (preview markdown rendering)
5. **Submit a pull request** with clear description
6. **Wait for review** (we'll respond within 1 week)

### For Issue Reports:

1. **Search existing issues** (avoid duplicates)
2. **Open a new issue** with:
   - Clear title (e.g., "LLM01-001: Test explanation unclear")
   - Description of the problem
   - Suggested improvement (if any)
3. **Engage in discussion** (we may ask follow-up questions)

### For Translations:

We welcome translations of **documentation only** (README, guides, contributing):
- **Target languages**: Turkish, Spanish, French, German, Portuguese, Japanese, Chinese
- **Format**: Create `README.[lang].md` (e.g., `README.tr.md` for Turkish)
- **Scope**: Translate explanatory text, keep test content in English
- **Quality**: Native speaker or professional translator preferred

### Be Respectful
- Use welcoming and inclusive language
- Respect differing opinions and experiences
- Accept constructive criticism gracefully
- Focus on what's best for the community

### Be Professional
- This is a security project—accuracy matters
- Cite sources when making claims
- Avoid self-promotion or spam
- Don't share vulnerabilities from real systems (ethical disclosure first)

### Be Educational
- Explain your reasoning
- Teach others through your contributions
- Share knowledge, not just code
- Help newcomers learn AI security
